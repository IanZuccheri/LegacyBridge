# Finite LegacyBridge source contract, revision 1

This is an independently structured, altered, application-specific selection
for LegacyBridge's existing simple-content-v1 registration interpreter. It is
not an original Mojang/MCPConfig distribution, a complete mapping table or an
API implementation. It does not authorize new semantic transformations.

Source aliases/declaration facts are checked against Minecraft 1.16.5 / Forge
36.2.42 development artifacts; their fingerprints are recorded in the TSV.
Official name references are verified with Mojang's mappings. Complete official
tables, obfuscated names, old game/Forge code and local API exports are absent.

SRG aliases originate in MCPConfig, Copyright (c) 2018 Forge Development LLC
and contributors. Its unmodified notice accompanies this artifact at
META-INF/legacybridge/legal/MCPConfig-LICENSE.txt.
Upstream: https://github.com/MinecraftForge/MCPConfig
