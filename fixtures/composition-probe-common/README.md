# Shared composition QA capture code

Java-8-compatible, JDK-only delegates/session/file/serialization implementation
compiled by the two separate native probe projects. This is not a public module,
adapter or conversion profile. Its tests do not load Minecraft or fixture classes.
The corpus compiles this main-source directory into its **test** source set only
to verify the recorder/checker protocol against synthetic delegates and inert
files. See [the complete contract](../../docs/COMPOSITION_PROBES.md).
